Syncing This Blog Straight From a Private Git Repo

2026-09-16 · 1 min read · [git] [ci]

Every time I fixed a typo in a post, I didn’t want to open a CMS, log in, and click through three menus. I wanted to open an editor, change the markdown, and push.

So that’s what this is: a folder of .md files in a git repo. Writing a post means creating a file. Publishing it means changing one line of front matter and running git push. A GitHub Actions workflow picks it up, rebuilds the site, and deploys it — no server to babysit, no database to back up.

$ git push origin main
-> build hook triggers
-> site regenerates in ~8s

The result reads fine on a laptop, on a phone on the train, and yes, one-handed in less convenient places too. That was the whole point.
